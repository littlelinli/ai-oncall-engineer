# Kezekshi: сайт

Статический сайт на HTML/CSS/JS без сборки. Можно открыть `index.html` прямо в браузере или залить папку в S3.

## Страницы

1. `index.html` — лендинг: что делает продукт и как это работает.
2. `dashboard.html` — дашборд: сводка, график за 14 дней, кнопки поломок, история и AI-разбор инцидента.
3. `connect.html` — подключение сервера: выбор облака (пока только AWS) и команда установки агента.

## Данные

1. Пока `API_URL` в `assets/config.js` пустой, дашборд показывает тестовые инциденты из `assets/mock-data.js`.
2. Когда API Gateway готов, вставьте его адрес в `API_URL`. Сайт будет вызывать `GET {API_URL}/incidents` и ждёт массив инцидентов (или объект `{ "items": [...] }`) в том же формате, что в `mock-data.js`.
3. На стороне API нужно включить CORS для домена сайта.
4. `DEMO_APP_URL` — адрес демо-приложения на EC2 для кнопок «Сломать сервис» (`/error`, `/cpu`, `/disk`, `/hang`).

## Деплой в S3

```bash
aws s3 sync . s3://<bucket-name> --exclude "README.md"
```
