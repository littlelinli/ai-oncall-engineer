# Расчёт стоимости

Регион eu-north-1 (Стокгольм), цены AWS on-demand на 28.10.2026 (из AWS Pricing API).
Месяц = 730 часов. Аккаунт платный, 12-месячного Free Tier нет; бесплатные навсегда лимиты
Lambda (1 млн запросов и 400 000 ГБ·с в месяц) действуют для любого аккаунта.
Gemini API и Telegram в расчёт не входят (это не AWS).

## Итого

| Режим | В месяц | Что платим |
|---|---|---|
| Демо-сервер работает 24/7 | **≈ $13.8** | EC2, IP, диск, метрики, алармы |
| Сервер остановлен (`demo-down`) | **≈ $4.6** | IP, диск, алармы |
| Час показа сверх этого | **≈ $0.012** | EC2 и метрики, пока сервер включён |
| Каждый подключённый сервер клиента | **≈ $2.0** | метрики и запросы от агента |

Пример: сервер выключен весь месяц, кроме 10 показов по 3 часа = $4.6 + 30 × $0.012 ≈ **$5.0**.

| Ресурс | Цена | В месяц |

| Алармы app-errors, cpu-high, disk-high | 3 × $0.10 | $0.30 |
| Логи CloudWatch (приложение и Lambda, < 0.1 ГБ) | $0.54 / ГБ | < $0.05 |
| Lambda, API Gateway, DynamoDB, S3, SNS | по запросам | < $0.05 |
| **Итого** | | **≈ $13.8** |

88% суммы составляют EC2, IP и диск, поэтому между показами сервер стоит выключать.

## Сервер остановлен

`scripts/demo-down` не удаляет сервер, а останавливает его. За EC2 AWS больше не берёт,
метрики не приходят, поэтому за них тоже не платим. Остаются:

| Ресурс | В месяц |
|---|---|
| Elastic IP (свободный IPv4 стоит столько же) | $3.65 |
| Диск EBS 8 ГБ | $0.67 |
| Алармы | $0.30 |
| **Итого** | **≈ $4.6** |

Зачем платить за IP и диск, когда сервер выключен: после `demo-up` у сервера тот же адрес и всё,
что на нём было установлено (агент, логи), а API, таблицы и ссылка на install.sh не меняются.
Если удалить вообще всё (`terraform destroy`), будет $0, но адреса API и IP придётся заново
раздавать команде.

## Один подключённый сервер клиента

Агент шлёт 1 запрос в минуту = 43 800 запросов в месяц.

| Ресурс | Расчёт | В месяц |
|---|---|---|
| Метрики cpu, mem, disk, error_count в CloudWatch | 4 × $0.30 | $1.20 |
| Запросы PutMetricData (1 вызов на все 4 метрики) | 43 800 × $0.01 / 1000 | $0.44 |
| Алармы на сервер (если #3 создаёт 3 штуки) | 3 × $0.10 | $0.30 |
| API Gateway HTTP API | 43 800 × $1.06 / млн | $0.05 |
| DynamoDB: чтение ключа + отметка online | 43 800 × ($0.13 + $0.67) / млн | $0.04 |
| Lambda /ingest (128 МБ, ~100 мс) | в бесплатном лимите | $0 |
| **Итого** | | **≈ $2.0** |

Основная часть — метрики CloudWatch. Отправлять все 4 метрики нужно одним вызовом
PutMetricData: при 4 отдельных вызовах запросы стоили бы $1.75 вместо $0.44.
